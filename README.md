# Battle Royale 3D - إعدادات البناء والرفع إلى GitHub

## محتويات الحزمة:
1. `.github/workflows/build-apk.yml`: ملف الأتمتة لبناء APK تلقائياً عند الرفع إلى GitHub.
2. `capacitor.config.ts`: ملف إعدادات تغليف اللعبة للأندرويد عبر Capacitor.
3. `package.json`: ملف الحزم والتبعيات المطلوبة للتشغيل والبناء.

## طريقة الاستخدام:
1. فك الضغط عن هذا الملف.
2. انسخ ملفات كود لعبتك (`src/`، `index.html`، `vite.config.ts`، إلخ) وضعها بجانب هذه الملفات في نفس المجلد الرئيسي.
3. ارفع محتويات المجلد مباشرة إلى الجذر الرئيسي (Root) لمستودعك على GitHub (وليس بداخل مجلد فرعي لتجنب خطأ ENOENT).
4. افتح تبويب **Actions** في GitHub وانتظر اكتمال البناء لتحميل `app-debug.apk`.
